Arquitectura del Sistema

El Sistema de Gestión de Procesos Empresariales sigue el patrón Model-View-Controller (MVC) con una arquitectura server-side rendida mediante Spring Boot y Thymeleaf.

Componentes principales

Controladores

Los controladores gestionan las peticiones HTTP y coordinan el flujo entre vistas. Cada controlador es responsable de un dominio específico del sistema.

Modelo de dominio

El modelo define las entidades del sistema: Empresas, Usuarios, Procesos, Actividades, Arcos, Gateways y Roles. Cada entidad está diseñada para operar dentro del contexto de una organización específica.

Vistas

Las vistas se renderizan con Thymeleaf, utilizando fragmentos reutilizables para navbar, sidebar y footer. Las plantillas siguen la convención de nombres del proyecto.

Aislamiento multiempresa

Cada registro en la base de datos está asociado a una organización. Las consultas filtran automáticamente por organización, garantizando que una empresa nunca pueda acceder a la información de otra.

Flujo de una petición

  1. El usuario realiza una petición HTTP (GET/POST).
  2. El controlador correspondiente recibe la petición.
  3. Se consulta el modelo de datos filtrando por organización.
  4. Se retornan los datos al controlador.
  5. El controlador pasan los datos a la vista.
  6. Thymeleaf renderiza la respuesta HTML.
