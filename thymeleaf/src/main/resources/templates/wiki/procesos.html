Gestión de Procesos

Los procesos son la unidad principal de trabajo en el sistema. Cada proceso contiene actividades conectadas por arcos y puede incluir gateways de decisión.

HU-04 Crear proceso

Como usuario, quiero crear un nuevo proceso, para documentar un flujo de trabajo de mi empresa.

HU-05 Editar proceso

Como usuario, quiero editar un proceso existente, para actualizar su información o estructura.

HU-06 Eliminar proceso

Como usuario, quiero eliminar un proceso, para remover documentación que ya no es necesaria.

HU-07 Consultar procesos

Como usuario, quiero consultar la lista de procesos, para encontrar y revisar la documentación existente.
