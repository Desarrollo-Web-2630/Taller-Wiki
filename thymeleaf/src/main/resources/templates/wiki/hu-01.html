HU-01 · Registro de empresa

Como representante de una empresa, quiero crear una cuenta empresarial, para que mi organización tenga un espacio propio donde administrar sus procesos y usuarios.

Contexto funcional

Esta historia define la base del sistema multiempresa. La empresa registrada se convierte en el contenedor principal de usuarios, procesos, roles y configuraciones, y sirve como eje para aislar la información entre organizaciones.

Criterios de aceptación

  • Se solicita nombre de la empresa, identificación fiscal o NIT y correo de contacto.
  • La identificación debe ser única dentro del sistema.
  • Se valida la estructura del correo antes de registrar la empresa.
  • Se crea automáticamente un usuario administrador inicial para la organización.
  • La empresa queda registrada como una entidad independiente y separada del resto.
  • Se muestran mensajes de error cuando faltan datos o el valor no es válido.

Nota de diseño

El espacio de cada empresa es independiente: dos organizaciones pueden tener procesos con el mismo nombre sin interferir entre sí.
