Autenticación

La gestión de autenticación comprende el registro de empresas, el registro de usuarios dentro de una empresa y el proceso de inicio de sesión.

HU-01 Registro de empresa

Como administrador del sistema, quiero registrar una nueva empresa, para que pueda usar el sistema de gestión de procesos.

HU-02 Registro de usuarios

Como administrador de empresa, quiero registrar nuevos usuarios dentro de mi empresa, para que puedan acceder al sistema.

HU-03 Inicio de sesión

Como usuario registrado, quiero iniciar sesión con mis credenciales, para acceder a las funcionalidades del sistema.
