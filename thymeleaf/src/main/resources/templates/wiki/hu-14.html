HU-14 Crear Gateway

Descripción

Como usuario, quiero crear un gateway de decisión, para definir puntos de bifurcación en el proceso donde se evalúa una condición.

Criterios de aceptación

  • El formulario solicita: nombre del gateway y tipo (exclusivo/inclusivo).
  • El gateway se inserta en el flujo entre dos actividades.
  • Se pueden definir las condiciones de cada rama de salida.
  • El gateway se visualiza en el diagrama con su icono correspondiente.

Estimación

3 puntos de historia de usuario.
