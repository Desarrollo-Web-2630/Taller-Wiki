HU-03 Inicio de Sesión

Descripción

Como usuario registrado, quiero iniciar sesión con mi correo electrónico y contraseña, para acceder a las funcionalidades del sistema.

Criterios de aceptación

  • El formulario solicita: correo electrónico y contraseña.
  • Las credenciales se validan contra la base de datos.
  • Si las credenciales son incorrectas, se muestra un mensaje de error genérico.
  • Al iniciar sesión, se crea una sesión válida para el usuario.
  • La sesión expira después de 30 minutos de inactividad.
  • Existe un enlace para recuperar la contraseña olvidada.

Estimación

2 puntos de historia de usuario.
