HU-03 · Inicio de sesión

Como usuario registrado, quiero iniciar sesión con mis credenciales, para acceder únicamente a la información y las operaciones autorizadas de mi empresa.

Contexto funcional

La autenticación es la pieza que define el contexto de negocio del usuario. Después del login, el sistema filtra procesos, permisos y usuarios de la empresa actual, asegurando el aislamiento entre organizaciones.

Criterios de aceptación

  • Se validan correo y contraseña antes de autorizar el acceso.
  • La contraseña se almacena cifrada y no se expone en texto plano.
  • En caso de credenciales incorrectas, se muestra un mensaje genérico.
  • La sesión debe quedar activa para el usuario autenticado.
  • Al cerrar sesión, se invalida el acceso y se elimina el contexto actual.

Nota de seguridad

Un inicio de sesión fallido no debe revelar si el correo existe o no en la base de datos, evitando filtraciones de información sensible.
