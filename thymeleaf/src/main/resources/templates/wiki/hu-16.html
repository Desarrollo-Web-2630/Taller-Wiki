HU-16 Eliminar Gateway

Descripción

Como usuario, quiero eliminar un gateway, para simplificar el flujo del proceso cuando la lógica de decisión ya no se necesita.

Criterios de aceptación

  • Se muestra un diálogo de confirmación.
  • Se eliminan las ramas de salida asociadas.
  • Las actividades conectadas al gateway se reconectan si es posible.
  • Se muestra un mensaje de éxito.

Estimación

2 puntos de historia de usuario.
