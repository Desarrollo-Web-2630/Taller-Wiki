HU-04 · Crear proceso

Como usuario autorizado, quiero crear un proceso, para registrar la estructura y el contenido de un flujo de trabajo dentro de la empresa.

Contexto funcional

Un proceso es el contenedor principal del diagrama BPMN. Al crearlo, se abre la base para luego añadir actividades, eventos, arcos, gateways y roles.

Criterios de aceptación

  • Se definen nombre, descripción y estado inicial del proceso.
  • El proceso queda asociado a la empresa del usuario autenticado.
  • El nombre del proceso debe ser único dentro de la organización.
  • La creación deja el proceso listo para ser editado y completado.
  • El proceso aparece inmediatamente en la lista general del usuario.

Nota técnica

El crear un proceso no significa construir automáticamente el diagrama completo; la historia define la creación del contenedor y su contexto de negocio.
