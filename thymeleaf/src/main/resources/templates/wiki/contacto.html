Contacto

Si tienes dudas sobre la documentación o el sistema, puedes usar el formulario de contacto para comunicarte con el equipo de desarrollo.

Campos del formulario

  • Nombre completo — Obligatorio. Mínimo 3 caracteres.
  • Correo electrónico — Obligatorio. Formato válido con @ y dominio.
  • Teléfono — Obligatorio. Solo números, entre 7 y 15 dígitos.
  • Asunto — Obligatorio. Seleccione una opción.
  • Mensaje — Obligatorio. De 20 a 400 caracteres.

Validaciones

Todas las validaciones se realizan en el lado del cliente mediante JavaScript. El formulario muestra mensajes de error específicos para cada campo y un contador de caracteres para el mensaje.
