Gestión de Gateways

Los gateways son puntos de decisión dentro de un proceso. Permiten bifurcar el flujo según condiciones específicas.

HU-14 Crear gateway

Como usuario, quiero crear un gateway de decisión, para definir puntos de bifurcación en el proceso.

HU-15 Editar gateway

Como usuario, quiero editar las condiciones de un gateway, para ajustar la lógica de decisión.

HU-16 Eliminar gateway

Como usuario, quiero eliminar un gateway, para simplificar el flujo del proceso cuando ya no se necesita.
