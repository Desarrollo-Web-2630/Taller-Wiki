Gestión de Arcos

Los arcos conectan actividades entre sí, definiendo el flujo de ejecución de un proceso. Cada arco tiene una actividad origen y una actividad destino.

HU-11 Crear arco

Como usuario, quiero crear un arco entre dos actividades, para definir la secuencia de ejecución del proceso.

HU-12 Editar arco

Como usuario, quiero editar las conexiones de un arco, para modificar el flujo del proceso.

HU-13 Eliminar arco

Como usuario, quiero eliminar un arco, para remover conexiones que ya no son válidas.
