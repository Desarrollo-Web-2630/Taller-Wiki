Gestión de Actividades

Las actividades son los pasos individuales dentro de un proceso. Cada actividad representa una tarea específica que se ejecuta como parte del flujo de trabajo.

HU-08 Crear actividad

Como usuario, quiero crear una nueva actividad dentro de un proceso, para documentar un paso del flujo de trabajo.

HU-09 Editar actividad

Como usuario, quiero editar una actividad existente, para corregir o actualizar su descripción.

HU-10 Eliminar actividad

Como usuario, quiero eliminar una actividad, para remover pasos que ya no forman parte del proceso.
