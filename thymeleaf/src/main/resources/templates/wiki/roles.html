Gestión de Roles

Los roles definen los permisos y responsabilidades de cada usuario dentro del sistema. El control de acceso se basa en los roles asignados.

HU-17 Crear rol

Como administrador, quiero crear un nuevo rol, para definir un conjunto de permisos específico.

HU-18 Editar rol

Como administrador, quiero editar un rol existente, para ajustar sus permisos según las necesidades de la empresa.

HU-19 Eliminar rol

Como administrador, quiero eliminar un rol, para remover permisos que ya no se utilizan.

HU-20 Consultar roles

Como administrador, quiero consultar la lista de roles, para revisar la configuración de permisos del sistema.
