Historias de Usuario

El sistema cuenta con 20 historias de usuario organizadas en 6 categorías. Cada historia describe una funcionalidad específica que el sistema debe soportar.

Categorías

  • Autenticación — HU-01 a HU-03: Registro de empresa, registro de usuarios y login.
  • Procesos — HU-04 a HU-07: Crear, editar, eliminar y consultar procesos.
  • Actividades — HU-08 a HU-10: Crear, editar y eliminar actividades dentro de un proceso.
  • Arcos — HU-11 a HU-13: Crear, editar y eliminar arcos de conexión.
  • Gateways — HU-14 a HU-16: Crear, editar y eliminar gateways de decisión.
  • Roles — HU-17 a HU-20: Crear, editar, eliminar y consultar roles del sistema.

Convenciones

Cada historia de usuario sigue el formato: Como [rol], quiero [acción], para [beneficio]. Las historias incluyen criterios de aceptación y estimación de esfuerzo.
