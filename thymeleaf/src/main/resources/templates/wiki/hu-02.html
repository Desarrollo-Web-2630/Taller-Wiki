HU-02 · Registro de usuario en empresa

Como administrador de empresa, quiero gestionar usuarios dentro de mi organización, para que cada colaborador acceda al sistema con el nivel de permisos adecuado.

Contexto funcional

Un usuario pertenece a una sola empresa y puede tener un rol de acceso dentro de la aplicación. Esta historia define la administración básica de acceso y explica la diferencia entre rol de acceso y rol de proceso.

Criterios de aceptación

  • Se puede crear un usuario con nombre, correo y rol de acceso.
  • Se valida que el correo no esté duplicado dentro de la empresa.
  • El administrador puede asignar roles como administrador, editor o solo lectura.
  • Un usuario puede desactivarse sin eliminar su historial de cambios.
  • Los procesos siguen siendo propiedad de la empresa, no del usuario.

Nota de diseño

El rol de acceso define qué puede hacer un usuario en la aplicación; el rol de proceso define la responsabilidad dentro del diagrama BPMN.
